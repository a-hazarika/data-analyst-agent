# Data Analyst Agent

An AI agent that answers business questions in plain English from two sources: a Postgres database (question to SQL) and a set of company policy documents (retrieval with citations). Each answer shows the SQL that ran, the passages it used and what the call cost.

**Status: in progress.** Built in public, week by week.

| Version | Adds | Status |
| --- | --- | --- |
| v0.1 | Question to SQL with guardrails: the model sees only a curated set of views, every query is validated before it runs, and each user sees only their own rows | In progress |
| v0.2 | Document search over PDF and Word files with cited answers | Planned |
| v0.3 | Agent with tools, an MCP server and tracing | Planned |
| v1.0 | Eval suite (accuracy, cost, latency), chat UI, CI/CD and a public demo | Planned |

## Stack

Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL 16 with pgvector, Docker Compose, pytest. Model: Claude API.

## Data

- **Database:** the [Olist Brazilian E-Commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), about 99,000 real orders across nine linked tables. The CSV files are not in this repo.
- **Documents:** 13 policy and FAQ documents in `documents/` for a fictional marketplace. They are invented for this project.
- **Names:** the dataset is anonymised. Customer and seller names are generated by `db/04_fake_names.sql` and are not real.

## Run it

You need Docker and the Olist CSV files.

1. Unzip the Olist CSV files into a `data/` folder at the repo root.
2. Copy `analyst-agent/.env.example` to `analyst-agent/.env` and fill in the values.
3. Start the database and the API:
   ```bash
   docker compose up -d --build
   ```
4. Create the tables and load the data:
   ```bash
   docker compose exec -T db psql -U postgres -d analyst -v ON_ERROR_STOP=1 -f /db/01_schema.sql
   docker compose exec -T db psql -U postgres -d analyst -v ON_ERROR_STOP=1 -f /db/02_load.sql
   docker compose exec -T db psql -U postgres -d analyst -v ON_ERROR_STOP=1 -f /db/04_fake_names.sql
   ```
5. Open http://localhost:8000/docs.

Run the tests with `docker compose run --rm api uv run pytest`.
